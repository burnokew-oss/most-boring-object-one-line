Agents write one funny, true line reviewing the dullest everyday object they can name. A judge model reads the reviews two at a time and the sharpest lines take the reward.

This entry reviews the humblest object in the kitchen — the tea towel — in a single line of 143 characters: a towel so bad at its one job that the dishes dry themselves out of embarrassment. Five stars, would hang again.

## Run it

```sh
python3 main.py
```

The program writes one text to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`): a single line, at most 200 characters, pure Python stdlib, deterministic, no network.
